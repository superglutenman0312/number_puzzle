# 🧩 數字華容道 Pro (Number Klotski Pro)

這是一款使用純前端技術 (Vanilla JS) 打造的現代化數字華容道網頁遊戲。結合了漸進式網頁應用程式 (PWA) 技術與雲端資料庫，讓玩家能在手機上獲得媲美原生 App 的沉浸式遊玩體驗，並與全球玩家競速！

🔗 **[點我直接遊玩 (Live Demo)](https://你的帳號.github.io/你的專案名稱/)**

---

## ✨ 核心特色 (Features)

* **支援超大盤面**：從經典的 3x3 到極具挑戰性的 12x12 (143 個方塊) 皆可自由選擇。
* **必定有解的生成演算法**：採用「反向打亂法 (Reverse Shuffle)」，透過模擬合法移動進行洗牌，從數學上 100% 保證每一局絕對有解。
* **🏆 全球即時排行榜**：串接 Google Firebase Firestore，過關後可輸入暱稱，與全世界的玩家爭奪最速通關紀錄（支援無限滾動瀏覽）。
* **原生 App 級體驗 (PWA)**：支援加入手機主畫面，隱藏瀏覽器網址列，享受全螢幕沉浸式遊玩。
* **防干擾設計**：透過 CSS `overscroll-behavior` 徹底封印 iOS Safari 的下拉重新整理機制，並配有防滑動的教學提示框，確保遊戲過程不中斷。
* **單機最佳紀錄**：利用 `localStorage` 自動記錄玩家在各個尺寸的個人最佳成績。

## 📱 如何安裝到手機 (iOS/iPhone)

為了獲得最佳體驗，建議將本遊戲加入手機主畫面(不確定Android系統能不能)：
1. 使用手機瀏覽器 開啟 [遊戲網址]([https://你的帳號.github.io/你的專案名稱/](https://superglutenman0312.github.io/number_puzzle/))。
2. 點擊畫面正下方的 **「分享」** 按鈕（正方形往上射出箭頭的圖示）。
3. 在選單中往下滑，選擇 **「加入主畫面 (Add to Home Screen)」**。
4. 點擊右上角的「新增」。
5. 回到手機桌面，點擊專屬的 App 圖示即可開始遊玩！

## 🎮 遊戲規則與操作方式

* **目標**：利用唯一的空格，將打亂的數字方塊按照「由小到大、從左到右、從上到下」的順序重新排列，最後一格必須為空格。
* **操作**：請使用手指 **「點擊」** 空格旁邊的數字來使其移動。
* **注意**：為確保流暢度，請勿使用手指「滑動」方塊，點擊即可瞬間完成移動。
